# 10_仏壇店サイト

〇〇県〇〇市の仏壇店（仮）のホームページ。
参考サイト（木原仏壇店 https://kihara-butudan.com/ ）の構成と雰囲気に寄せて作成した、複数ページの静的サイト。

## ページ構成

| ページ | ファイル |
| --- | --- |
| トップページ | `index.html` |
| 当店について | `about/index.html` |
| 仏壇・仏具のご案内 | `products/index.html` |
| 仏壇の修繕 | `repair/index.html` |
| 店舗案内 | `shop/index.html` |
| ご相談・お問い合わせ | `contact/index.html` |

## フォルダ構成

```
10-butsudan-site/
├── index.html ほか各ページ
├── assets/
│   ├── css/style.css   … 全ページ共通のデザイン
│   ├── js/main.js      … 動き（ページ遷移のフェード、スライド、メニュー開閉など）
│   └── img/            … 写真（無料素材。出典は 制作指示.md）
├── _parts/             … 全ページのHTMLを組み立てるスクリプト
└── .claude/serve.ps1   … 確認用のローカルサーバー（http://localhost:8127/）
```

## デザインの特徴

- 明朝体（Shippori Mincho）と縦書きの見出し、和紙のような地色、金のアクセント
- トップは全画面スライド（ゆっくりズームしながらクロスフェード）、左に縦長のロゴ帯
- ページを移るとき、ふわっとフェードアウト → フェードイン
- スクロールに合わせて内容がふわっと表示される
- 本文は18px前後と大きめ。スマホでは本文を横書きにし、画面下に「電話で相談／メールで相談」を固定

## ヘッダー・フッターを直すとき

静的HTMLなので、ヘッダー・フッターは各ページに実体がある。
全ページまとめて直すときは `_parts/parts.sh` を編集して、次を実行する。

```bash
bash _parts/build.sh
```

各ページの中身は `_parts/body-〇〇.html` にある。`index.html` を直接直した場合は、
同じ修正を `body-〇〇.html` にも入れておくこと（次に build.sh を実行すると上書きされるため）。

## 確認方法

`index.html` をブラウザで直接開いても表示できる（パスはすべて相対パス）。
